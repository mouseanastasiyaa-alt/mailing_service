# Сервис управления рассылками

Курсовой проект по разработке веб-приложения на Django для управления рассылками сообщений.

## Описание проекта

Сервис позволяет создавать, редактировать и удалять:
- **Получателей рассылки** (клиентов).
- **Сообщения** (тема и тело письма).
- **Рассылки** (с указанием времени начала/окончания и списком получателей).

Также реализована **ручная отправка** писем через веб-интерфейс и **командную строку**, сбор **статистики** по попыткам отправки и **кеширование** для повышения производительности.

## Функционал

### Часть 1: Разработка сервиса
- CRUD-операции для получателей, сообщений и рассылок.
- Валидация дат: `start_time` не может быть в прошлом, `start_time` должен быть раньше `end_time`.
- Динамическое вычисление статуса рассылки (`Создана`, `Запущена`, `Завершена`).
- Отправка писем по требованию (проверка интервала времени, отправка каждому получателю).
- Сохранение попыток отправки (успешные/неуспешные) с текстом ответа сервера.
- Главная страница со статистикой (всего рассылок, активных, уникальных получателей).

### Часть 2: Расширение функциональности
- Регистрация пользователей с подтверждением email.
- Аутентификация (вход/выход) и восстановление пароля.
- Роли: **Пользователь** (видит только свои данные) и **Менеджер** (видит всё, может блокировать пользователей и отключать рассылки).
- Страница статистики с детализацией по каждой рассылке (успешные/неуспешные попытки).
- Серверное и клиентское кеширование.

## Технологии

- **Python 3.14**

## Установка и запуск

1. Клонируй репозиторий:
   ```bash
   git clone <URL_репозитория>
   cd mailing_service
   
## Создай виртуальное окружение и активируй его:

python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

## Установи зависимости:

pip install -r requirements.txt

## Примени миграции:

python manage.py migrate

## Создай суперпользователя (для доступа в админку):

python manage.py createsuperuser

## Запусти сервер:

python manage.py runserver

## Перейди в браузере по адресу:

http://127.0.0.1:8000/

## Отправка писем (для разработки)

Для тестирования используется консольный бэкенд (письма выводятся в терминал).
Настройки в config/settings.py:

MAILERS = {
    "default": {
        "BACKEND": "django.core.mail.backends.console.EmailBackend",
    },
}

## Команда для отправки рассылок из консоли

python manage.py send_mailings

Команда находит все активные рассылки (статус «Запущена» и текущее время в интервале) и отправляет письма.

## Роли и права доступа

Пользователь: создание, просмотр, редактирование и удаление своих клиентов и рассылок; просмотр статистики по своим рассылкам.

Менеджер: просмотр всех клиентов и рассылок; просмотр списка пользователей; блокировка пользователей; отключение рассылок.

## Статистика

На странице /statistics/ отображается:

Общее количество отправленных сообщений (успешных попыток).

Количество успешных и неуспешных попыток.

Детализация по каждой рассылке (успешные/неуспешные попытки).
